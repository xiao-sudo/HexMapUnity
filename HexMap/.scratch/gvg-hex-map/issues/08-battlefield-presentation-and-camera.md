# 08 — 战场地图表现与镜头控制

**What to build:** 在 Unity 场景中将 GVG 地图状态、队伍和移动路线呈现出来，并提供可用于战场操作的镜头控制。

**Blocked by:** 06 — GVG 地块选择与交互反馈; 07 — GVG 移动、目标选择与路径失效处理.

**Status:** ready-for-agent

- [ ] 地块类型、归属色、阻碍、开放状态、当前队伍和其他移动队伍具有可区分的场景表现。
- [ ] 移动队伍显示与路径数据一致的路线表现，路线更新不会污染真实逻辑位置。
- [ ] 玩家可以拖拽和缩放地图，镜头始终受地图边界限制。
- [ ] 进入战场时可以定位到己方大营或当前队伍位置，并可通过代码聚焦指定 Hex 或 Plot。
