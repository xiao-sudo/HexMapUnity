# 04 — 通用寻路与路径表现数据

**What to build:** 提供不包含 GVG 概念的通用 Hex 寻路，并将成功路径转换为移动表现可以直接使用的世界坐标点列表。

**Blocked by:** 01 — Hex 坐标与布局内核; 02 — 运行时 Hex 地图与格子拾取.

**Status:** ready-for-agent

- [ ] 寻路接受起点、多个目标、CanPass 判断和 CanEnter 判断。
- [ ] 在合成地图上正确返回可达路径、最近可达目标和无路径结果。
- [ ] 返回的 Hex 路径可以转换为稳定的世界坐标中心点列表。
- [ ] 通过纯 C# EditMode 测试覆盖成功、失败、阻挡和多目标选择。
