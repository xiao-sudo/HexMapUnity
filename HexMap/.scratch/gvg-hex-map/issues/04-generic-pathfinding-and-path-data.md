# 04 — 通用寻路与路径表现数据

**What to build:** 提供不包含 GVG 概念的通用 Hex 寻路，并将成功路径转换为移动表现可以直接使用的世界坐标中心点列表。

**Blocked by:** 01 — Hex 坐标与布局内核；02 — 运行时 Hex 地图与格子拾取。

**Status:** ready-for-agent

## 范围与职责边界

寻路核心只处理地图中的 Hex、路径搜索和调用方提供的判断回调，不直接理解 GVG、阵营、归属或城池。

寻路请求应包含：

- 一个起点 Hex：Start；
- 一个或多个目标 Hex：Targets；
- 一个由调用方提供、寻路核心不解释的上下文：Context；
- CanPass(cell, context) 回调；
- CanEnter(cell, context) 回调。

Context 可以携带行动者阵营、行动类型或其他上层规则所需的信息。CanPass 和 CanEnter 使用同一个上下文，以便调用方保持规则一致。

城池不进入通用寻路 API。上层将城池展开为多个组成 Hex 后，继续使用多目标寻路；寻路结果只返回最终抵达的 Hex，调用方可以根据该 Hex 反查城池。

## 通行与目标规则

- Start 必须是当前地图中的有效 Hex，但 Start 不需要满足 CanPass。
- 如果 Start 本身是目标，返回成功，路径为只包含 Start 的单格列表，路径代价为 0。
- 每个非目标中间 Hex 必须满足 CanPass，才能进入并继续搜索。
- CanEnter 只用于目标候选的最终抵达判断，不用于普通中间 Hex。
- 目标 Hex 可以不满足 CanPass，但必须满足 CanEnter 才能作为最终节点。这允许非己方 Hex 作为争夺目标，但不允许它出现在路径中间。
- 从非己方起点出发是合法的，可以离开当前起点。从第二个节点开始，遵守正常的 CanPass 规则。
- 到达目标后的攻击、争夺或占领逻辑由调用方负责。

## 城池目标

- 城池由多个 Hex 组成，这些组成 Hex 必须构成边相连的连通集合。
- 不要求城池区域无空洞，也不设置城池中心格或固定入口格。
- 所有组成 Hex 的归属必须与城池归属一致。
- 所有组成 Hex 都是候选目标；上层负责将城池展开为 Targets。
- 寻路选择从起点到城池组成 Hex 中实际路径代价最小的可达 Hex。

## 代价与确定性选择

- 当前每次跨越相邻 Hex 的代价固定为 1，因此最近目标按路径步数最少判定。
- 多个目标具有相同的最小代价时，按稳定坐标顺序裁决，例如先比较 q，再比较 r。
- 同一个目标存在多条等长路径时，按固定的邻居方向顺序扩展，选择首次找到的路径。邻居方向顺序必须稳定，并由测试锁定。
- 目标列表中的重复 Hex 必须去重，且不能改变结果。

## 输入校验与结果

Start 和 Targets 中的 Hex 必须属于当前地图的实际 Hex 集合：

- Start 不在地图中：返回 InvalidInput.StartMissing；
- 不在地图中的目标：过滤掉该目标；
- 目标列表为空，或过滤后没有合法目标：返回 InvalidInput.NoValidTargets；
- 存在合法目标，但没有任何目标可达：返回 NoPath.NoReachableTarget。

成功结果至少包含：

- Status；
- Cells：按“起点 → 终点”排列，并包含起点和终点的 Hex 路径；
- ReachedTarget：实际抵达的 Hex；
- Cost：路径代价；
- Reason：失败时用于说明原因的字段。

成功路径的 Cost 等于路径边数。失败时不能返回可执行的成功路径，并且状态必须明确区分输入错误和没有可达目标。

一次寻路调用期间，地图、归属以及回调观察到的状态视为稳定。寻路模块不监听状态变化；路径执行前或每一步移动前由调用方重新验证，路径失效后由调用方重新寻路。

## 表现数据

PathResult 只保存权威的 Hex 路径。应提供独立的转换方法，根据布局将 Cells 转换为稳定的世界坐标中心点列表，供移动表现直接使用。世界坐标属于表现层派生数据，不应成为寻路核心的权威结果。

## 验收标准

- [ ] 寻路接受起点、多个目标、调用方上下文、CanPass 和 CanEnter，核心不包含 GVG 或城池类型。
- [ ] 起点校验、起点即目标、非己方起点离开和目标最终进入规则符合本 Spec。
- [ ] 在合成地图上正确返回成功路径、实际抵达的最近目标和明确的无路径原因。
- [ ] 非己方目标可以在最后一步进入，但不能作为路径中间节点。
- [ ] 城池可以展开为多个相邻 Hex 目标，并选择最近可达的组成 Hex。
- [ ] 重复目标去重；无效目标过滤；全部目标无效时返回 InvalidInput.NoValidTargets。
- [ ] 等代价目标和等长路径的选择具有确定性。
- [ ] Hex 路径可以转换为稳定的世界坐标中心点列表。
- [ ] 通过纯 C# EditMode 测试覆盖成功、起点即目标、非己方起点、阻挡、最终目标例外、多目标、城池多 Hex、重复目标、无效目标、明确的无路径原因和确定性 tie-break。
