# 06 — GVG 地块选择与交互反馈

**What to build:** 玩家点击任意地块格子时都能选中完整 Plot，并获得足以理解当前目标和下一步操作的反馈。

**Blocked by:** 05 — GVG 地块模型与战场状态规则.

**Status:** ready-for-agent

- [ ] 点击多格 Plot 的任意 Hex 都选中同一 Plot，并对其全部 Hex 显示选中特效。
- [ ] 选中结果显示名称、归属和代表坐标；归属状态提供正确的讨伐或驻守操作入口。
- [ ] 点击阻碍、未开放或不可达目标时显示明确反馈，不会误触发有效操作。
- [ ] 交互测试覆盖单格 Plot、多格 Plot、阻碍和未开放 Plot。
