# 07 — GVG 移动、目标选择与路径失效处理

**What to build:** 队伍可以从当前具体 Hex 移动到目标 Plot，并在战场状态变化时保持移动结果与规则一致。

**Blocked by:** 04 — 通用寻路与路径表现数据; 05 — GVG 地块模型与战场状态规则.

**Status:** ready-for-agent

- [ ] 目标是多格 Plot 时，移动系统自动选择最近的合法目标 Hex，且队伍当前位置记录为具体 Hex。
- [ ] 队伍按 Hex 路径逐格移动，每格使用固定或配置出的时间；逻辑位置与视觉插值位置分离。
- [ ] 路径表现能区分自己、友方和敌方移动线，并支持移动中改变目标。
- [ ] 路径中途因归属、开放状态或阻挡变化失效时能够重算或进入断路状态。
- [ ] 不连通目标返回铺路提示，并提供最近可用断点供镜头或交互定位。
