# 11 — 地图验证与寻路调试工具

**What to build:** 在地图导出前发现配置错误和连通性问题，并让设计师可以在编辑器中直接调试关键路线。

**Blocked by:** 04 — 通用寻路与路径表现数据; 05 — GVG 地块模型与战场状态规则; 10 — 地图配置编辑、预览与导出.

**Status:** ready-for-agent

- [ ] 检查重复 Hex 占用、引用不存在的 Hex、多格 Plot 不连通、代表格或可停驻格不属于对应 Plot。
- [ ] 检查大营配置缺失或数量错误、重要地块不可达、阻碍造成的异常分区，以及阶段性开放或替换后的无效地图状态。
- [ ] 编辑器可以选择起点和终点预览寻路结果，并清楚区分成功路径、不可达目标和推荐断点。
- [ ] 导出前自动运行验证；存在错误时阻止地图进入运行时，并提供可定位的错误信息。
