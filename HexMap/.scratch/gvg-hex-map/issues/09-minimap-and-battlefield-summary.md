# 09 — 小地图与战场统计派生视图

**What to build:** 从主地图运行时数据派生一个可浏览的小地图和战场摘要，让玩家能快速理解全局态势。

**Blocked by:** 05 — GVG 地块模型与战场状态规则; 08 — 战场地图表现与镜头控制.

**Status:** ready-for-agent

- [ ] 小地图复用主地图的 Hex 和 Plot 状态，不维护第二套地图数据。
- [ ] 小地图打开时以当前队伍所在 Hex 为中心，并支持左右拖动浏览其他区域。
- [ ] 小地图显示队伍位置、地块归属、大营信息和城池名称。
- [ ] 归属或状态变化后，小地图和占领数量、总地块数、势力积分、排名等摘要数据同步刷新。
